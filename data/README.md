# Dataset Instructions
The actual MRI brain tumor slices (kaggle_3m) are excluded from this repository due to size limits.
To run the notebook, download the dataset from Kaggle:
[LGG MRI Segmentation Dataset](https://www.kaggle.com/datasets/mateuszbuda/lgg-mri-segmentation)
and extract it to `/content/kaggle_3m` (if using Colab) or your local `data/kaggle_3m/` directory.
